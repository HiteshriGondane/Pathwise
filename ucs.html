01 / UCS BASICS

What does UCS mean?

Uniform Cost Search is a pathfinding algorithm that always explores the route with the lowest total cost found so far.

In simple words

Cheapest route first.

Imagine travelling between cities. Each road has a price or distance. UCS checks the cheapest possible journey so far before trying a more expensive one.

Remember: UCS compares the sum of edge costs from the start—not simply how many steps a path has.
Example

Shorter is not always cheaper.

Route S → B → G has 2 edges costing 5 + 8 = 13. Route S → A → C → G has 3 edges costing 2 + 2 + 3 = 7. UCS chooses the second route because 7 is less than 13.

The key formula

UCS path-cost formula

The priority of a node is its total cost from the start node.

f(n) = g(n) = g(parent(n)) + c(parent(n), n)

For the start node, g(start) = 0. For any next node, add the edge cost to the total cost used to reach its parent.

f(n) — priority of node n

The value UCS uses to decide which frontier node to expand next. In UCS, f(n) = g(n).

g(n) — cumulative path cost

The sum of all edge costs along the path from the start node to node n.

parent(n) — previous node

The node immediately before n on the current best-known path.

c(parent(n), n) — edge cost

The cost of moving directly from the parent node to node n, such as distance, time, or money.

Example: If the cost to reach A is g(A) = 4 and edge A → B costs 3, then g(B) = 4 + 3 = 7. UCS gives B priority 7 and expands the frontier node with the smallest cumulative cost first.
Conditions to remember

When does UCS give the optimal route?

01. Non-negative costs

Every edge cost must be zero or positive. Negative edge costs can break UCS's optimality guarantee.

02. Cheapest-first queue

The frontier must be ordered by cumulative path cost, usually with a priority queue.

03. Goal is removed

Stop when the goal is removed from the priority queue as the cheapest valid entry—not merely when first discovered.

UCS is complete under the usual finite-branching assumptions when step costs are bounded below by a positive value. With zero-cost edges, termination depends on the graph/search handling and assumptions.
